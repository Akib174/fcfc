# fcfc 🚀

**সম্পূর্ণ এন্ড-টু-এন্ড এনক্রিপ্টেড, রিয়েল-টাইম, ইনস্টলযোগ্য (PWA) চ্যাট অ্যাপ্লিকেশন** — টেলিগ্রাম/সিগন্যাল-অনুপ্রাণিত ডিজাইন, ফ্রেমার মোশন অ্যানিমেশন, ক্লাউডফ্লেয়ারের সম্পূর্ণ ইকোসিস্টেমে তৈরি।

> ⚡ **ডিপ্লয় এক কমান্ডে:** টোকেন বানিয়ে (dash.cloudflare.com → My Profile → API Tokens → "Edit Cloudflare Workers" টেমপ্লেট):
> ```bash
> export CLOUDFLARE_API_TOKEN="আপনার-টোকেন"   # Windows PS: $env:CLOUDFLARE_API_TOKEN="..."
> node deploy.mjs
> ```
> D1/KV/R2, মাইগ্রেশন, সিক্রেট, বিল্ড, ডিপ্লয় — সব অটো, অ্যাপ+API একটাই URL-এ। বিস্তারিত: [`DEPLOYMENT-GUIDE.md`](./DEPLOYMENT-GUIDE.md)-এর "দ্রুততম উপায়" অংশ।
>
> 🆕 **একদম নতুন?** প্রতিটি কমান্ড ও ক্লিক সহ ধাপে ধাপে গাইড: **[`DEPLOYMENT-GUIDE.md`](./DEPLOYMENT-GUIDE.md)**

### 🔐 এনক্রিপশন মডেল (Signal-অনুপ্রাণিত)
- প্রতি ইউজার: **Identity Key (X25519)** + সাইনড প্রিকি + ২০টি ওয়ান-টাইম প্রিকি — ক্লায়েন্টে জেনারেট হয়, প্রাইভেট কী কখনো সার্ভারে যায় না।
- **X3DH**-এর মতো প্রাথমিক হ্যান্ডশেক → **Double Ratchet** (প্রতি মেসেজে আলাদা কী, ফরওয়ার্ড সিক্রেসি)।
- গ্রুপে **Sender Keys**: প্রতি মেম্বারের চেইন-কী ১:১ এনক্রিপ্টেড চ্যানেলে বিতরণ হয়; নতুন মেম্বার জয়েন করলে জেনেসিস-কী শেয়ার হয় বলে সে **আগের হিস্টোরিও** পড়তে পারে।
- ফাইল/মিডিয়া আপলোডের **আগে** ক্লায়েন্টে এনক্রিপ্ট হয় (১-মিলিয়ন-বাইট চাঙ্ক, কী মেসেজ-পেলোডে)।
- **কী-ব্যাকআপ**: পাসওয়ার্ড থেকে ডেরাইভ করা কী (PBKDF2 ৬০০k) দিয়ে প্রাইভেট কী বান্ডিল এনক্রিপ্ট করে সার্ভারে থাকে — পাসওয়ার্ড ছাড়া ডিক্রিপ্ট অসম্ভব।
- পাসওয়ার্ড সার্ভারে হ্যাশড অবস্থায় থাকে। **কোনো রিকভারি নেই** — পাসওয়ার্ড ভুলে গেলে অ্যাকাউন্ট চিরতরে অ্যাক্সেসযোগ্য নয় (এটাই প্রাইভেসির দাম)।

## 🚀 ডিপ্লয়মেন্ট গাইড (ধাপে ধাপে)

### পূর্বশর্ত
- [নোড ≥ 18](https://nodejs.org), [Cloudflare অ্যাকাউন্ট](https://dash.cloudflare.com) (ফ্রি প্ল্যানেই চলবে), `npm i -g wrangler` ও `wrangler login`

### ১. ব্যাকএন্ড রিসোর্স তৈরি

```bash
cd worker
npm install

wrangler d1 create fcfc-db            # → যে database_id পাবেন
wrangler kv namespace create KV       # → যে id পাবেন
wrangler r2 bucket create fcfc-media
```

`wrangler.toml`-এ `database_id` ও KV `id` বসান। তারপর মাইগ্রেশন:

```bash
wrangler d1 migrations apply fcfc-db          # প্রোডাকশন
wrangler d1 migrations apply fcfc-db --local  # লোকাল টেস্ট
```

### ২. সিক্রেট সেট করুন

```bash
npm run vapid                          # VAPID কী জেনারেট করে দেখাবে
wrangler secret put JWT_SECRET         # যেকোনো লম্বা র‍্যান্ডম স্ট্রিং
wrangler secret put REFRESH_PEPPER
wrangler secret put VAPID_PUBLIC_KEY   # জেনারেটরের আউটপুট (৮৮ অক্ষরের পয়েন্ট)
wrangler secret put VAPID_PRIVATE_KEY
wrangler secret put PUSH_CONTACT       # যেমন: mailto:you@example.com
wrangler secret put CALLS_API_TOKEN    # Cloudflare Calls API টোকেন (কল না চালালে বাদ দেওয়া যায়)
```

### ৩. ওয়ার্কার ডিপ্লয়

```bash
wrangler deploy
# → https://fcfc-backend.<your-subdomain>.workers.dev — এটাই আপনার API বেস (ডোমেইন কোথাও হার্ডকোড নেই)
```

### ৪. ফ্রন্টএন্ড সেটআপ + ডিপ্লয়

```bash
cd ../frontend
npm install
cp .env.example .env                   # VITE_API_BASE=https://fcfc-backend.<your-subdomain>.workers.dev
npm run build                          # dist/ তৈরি হবে
wrangler pages project create fcfc     # (প্রথমবার)
wrangler pages deploy dist --project-name=fcfc
```

### ৫. কাস্টম ডোমেইন যুক্ত করা (ঐচ্ছিক)

1. **ওয়ার্কার**: ড্যাশবোর্ড → `fcfc-backend` → Settings → Domains & Routes → আপনার ডোমেইনের একটি সাবডোমেইন যোগ করুন (যেমন `api.আপনার-ডোমেইন`)।
2. **পেজেস**: `fcfc` প্রজেক্ট → Custom domains → মূল ডোমেইন বা `app.আপনার-ডোমেইন` যোগ করুন।
3. ফ্রন্টএন্ডের `.env`-এ `VITE_API_BASE=https://api.আপনার-ডোমেইন` দিয়ে আবার `npm run build && wrangler pages deploy dist`।
4. (রেকমেন্ডেড) ওয়ার্কারের `src/index.ts`-এর CORS হেডার `access-control-allow-origin: *` সরিয়ে শুধু আপনার ফ্রন্টএন্ড অরিজিন দিন।

> ডোমেইন নাম কোডে কোথাও হার্ডকোড করা নেই — শুধু `.env` আর ড্যাশবোর্ড সেটিং বদলালেই যেকোনো ডোমেইনে চলবে।

### ৬. লোকাল ডেভেলপমেন্ট

```bash
# টার্মিনাল ১ — ব্যাকএন্ড (worker/.dev.vars ফাইলে সিক্রেট কপি করুন)
cd worker && cp .dev.vars.example .dev.vars && npm run dev

# টার্মিনাল ২ — ফ্রন্টএন্ড
cd frontend && printf 'VITE_API_BASE=http://localhost:8787\n' > .env && npm run dev
```

## 📞 Cloudflare Calls সেটআপ (ভিডিও/ভয়েস কল)

1. ড্যাশবোর্ড → **Calls** → API টোকেন তৈরি করুন।
2. `wrangler secret put CALLS_API_TOKEN` দিয়ে সেট করুন।
3. বাকিটা কোড হ্যান্ডেল করে: ওয়ার্কার সেশন তৈরি ও `tracks/new` নেগোসিয়েশন প্রক্সি করে (টোকেন ক্লায়েন্টে কখনো যায় না); ক্লায়েন্ট সরাসরি SFU-র সাথে মিডিয়া আদান-প্রদান করে। গ্রুপ কল, স্ক্রিন শেয়ার ও মিড-কল জয়েন সাপোর্টেড।

## 🔔 পুশ নোটিফিকেশন

- সেটিংস → নোটিফিকেশন → "চালু করুন" (ব্রাউজার পারমিশন লাগবে)।
- অ্যাপ বন্ধ থাকলেও সার্ভিস ওয়ার্কার পুশ ধরে নোটিফিকেশন ট্রে-তে দেখায় (সাউন্ড ডিভাইস-নির্ভর; ইন-অ্যাপ পিং সাউন্ড সবসময় বাজে)।
- নতুন ডিভাইস লগইন অ্যাপ্রুভালও পুশ আকারে যায়।

## ⚠️ সীমাবদ্ধতা / নোট

- ≤১০০ ইউজার স্কেলের জন্য ডিজাইন করা; আর্কিটেকচার প্র্যাকটিকাল রাখা হয়েছে।
- ওয়ার্কার রানটাইমে নেটিভ আর্গোন২ নেই বলে **PBKDF2-SHA256 (৬০০k)** ব্যবহৃত — চাইলে `worker/src/lib/password.ts`-এ WASM-আর্গোন২ বসানো যায় (ইন্টারফেস একই)।
- টোকেন `localStorage`-এ থাকে (স্ট্যান্ডার্ড SPA প্যাটার্ন); চাইলে `localStorage`-এ এনক্রিপ্টেড রাখা যায়।
- 2GB ফাইল এনক্রিপশন ব্রাউজার মেমোরিতে হয় — বড় ফাইলে যথেষ্ট র‍্যাম থাকা ডিভাইসে সুপারিশকৃত।
- ব্রাউজার `X25519` WebCrypto সাপোর্ট করে (আধুনিক ক্রোম/এজ/ফায়ারফক্স/সাফারি)।
